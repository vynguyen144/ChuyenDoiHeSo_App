Giới thiệu công cụ

Ứng dụng tích hợp hỗ trợ học tập và thực hành các môn Kiến trúc máy tính và Quản trị mạng.

🔄 1. Đổi hệ cơ số

Hỗ trợ chuyển đổi nhanh giữa các hệ đếm: Nhị phân (Bin - 2), Bát phân (Oct - 8), Thập phân (Dec - 10), và Thập lục phân (Hex - 16) kèm các bước giải thích chi tiết phép nhân/chia.

🌐 2. Tự động chia mạng con

Nhập bất kỳ đề bài mạng nào (chia theo số lượng Subnet hoặc số Host mỗi phòng ban). Hệ thống tự phân tích lớp mạng, bit mượn, Subnet Mask mới, bước nhảy và xuất bảng địa chỉ chi tiết theo đúng mẫu bài nộp Word.

💡 Hướng dẫn nhanh

• Nhấn tab Đổi hệ cơ số để chuyển đổi các hệ số từ 2, 8, 10, 16.

• Nhấn tab Chia mạng con (Subnet) để nhập địa chỉ IP mạng và số mạng con/host cần chia để xem bảng giải bài tập tự động và xuất file Word.
